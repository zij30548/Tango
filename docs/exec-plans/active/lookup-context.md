## 目标与验收

用户查歌后，能继续说“第二首”“录音室版那个”“不要现场版”“换成另一个歌手”及明确歌手，在当前原始候选中只读筛选。人声性别没有可信字段时先追问，不从歌手名、现场标记或模型记忆推断，也不部分满足复合条件后声称完成。

1. 当前指代绑定账号、设备、会话、原消息/动作和候选版本；过期、重开、新话题、新会话、换号或迟到响应不能复用旧权限。
2. 新增只读music.refine能力，来源必须完整当前原句，不允许播放、记忆、任意ID/URL或混合其他动作。当前输入理解与程序执行分别验收。
3. 索引只针对当前真正展示的有序候选；版本、排除、歌手条件重新筛同一原始候选池，界面明确本轮条件，便于纠正；“另一个歌手”需当前唯一歌手作为锚。
4. 原始候选有界20条，实际界面最多12条，只提交用户真正见过的候选；未知或冲突版本不能当作录音室版。
5. 后台验证原持久路由同账号设备会话及相邻消息；连续筛选验证原池和可见ID确由上次selector派生，幂等比较包含整个上下文。候选来自设备，后台验证契约不等于认证网易云事实。
6. 原始查询10分钟过期，连续筛选不延长；只读澄清可以承接同一上下文。重启后无内存候选时请求重新查找，不从聊天文本重建可执行候选。
