# 第 3 步计划：真实 MCP 曲库工具

状态：待实施。依据 [路线图](../../AGENT_UPGRADE_ROADMAP.md) 与 [Harness 规范](../../HARNESS_ENGINEERING.md)。本轮建立开发约束，没有接通 MCP。

## 目标和边界

实际 MCP client 能发现并调用两个只读曲库能力，复用现有网易云适配，Cookie 和播放授权留在设备。工具来源、失败、取消和恢复可追踪；不自动写记忆或采用歌单，不修改账号体系。

## 实施顺序

1. 核对官方文档并冻结协议/SDK 版本，确定进程、传输、端点身份、schema、版本与错误码。
2. 定义只读工具权限、数据来源、超时、取消、大小上限及模型可见字段。
3. 实现实际 server/client 的协商、工具列表与调用，先以隔离本机模拟上游验证协议。
4. 接回本机适配和检查点，保持账号/设备/revision/lease/取消守卫；工具数据不能更改权限。
5. 验证恢复和并发，保留失败；真实曲库联通单独记录，不用模拟结果代替。

## 验收矩阵

| Harness 类别 | 本步必须证明 |
| --- | --- |
| 上下文与记忆 | 结果与指令分开、有大小界限，不自动变成用户偏好 |
| 工具与权限 | 实际发现/调用；未知工具、错误参数、版本不兼容、越权、端点和来源边界 |
| 执行与状态 | 超时、取消、重复回执、旧租约、断连恢复，不重放付费请求或自动播放 |
| 评测与反馈 | 协议离线测试及真实曲库分开；固定输入保留 HTTP 适配对照、调用数和延迟 |
| 可观测性与恢复 | 消息/任务/工具/尝试可关联，受限错误分类，不记录 Cookie/Key/完整用户文本 |

## 完成条件和回退

真实 client/server 联通、守卫测试、当前 Qt 业务接入、文档与证据均完成才更新状态；缺关键证据保持 partial。退路必须显式、同权限且可追踪，不能自动切到绕过验证的旧工具或旧用户库。

新增预算、云端偏好迁移或额外播放副作用超出现有授权时另行说明；本计划不授予真实模型调用预算。
