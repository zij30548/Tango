## 这一步在做什么

前几轮固定模型与合成曲库测试验证了程序衔接，例如候选筛选、权限、确认和恢复。现在需要检验真实模型面对自然说法时，能否选择正确行动并把任务完成。旧24题的失败与分数原样保留，不用新成绩覆盖。

本轮先准备题目、判据和预算，离线确认执行链能采到最终证据；新预算明确授权后再运行真实模型。旧200次中的未用124次以及历史额度都不沿用。

## 怎么测

1. **冻结题目与判据**：16个新任务和8个修复回归分开统计。每题写明用户目标、允许的等价路由、关键字段、最终状态和禁止副作用。
2. **离线检查接线**：真实Qt输入经过正式HTTP和Python后台，曲库使用固定真值与隔离账号，检查观测能关联到本轮消息、路由和任务。
3. **一次真实模型执行**：所有角色、前置、失败和超时共用新授权的硬上限，不自动付费重跑，不额外使用模型裁判。
4. **核验最终事实**：同时查看实际候选、歌单、偏好版本、播放队列、后台任务和调用账本。助手说“完成了”不能单独算完成。
5. **复核语义并保留失败**：推荐是否相关、解释是否充分、追问是否必要单独复核；不确定项保留未知，修复时转入回归。

本轮冻结计划包含24个任务、52次正式交互：40条自然语言和12次本机命令或界面动作，另外有3条前置自然语言。前置也消耗共享预算，不参与正式任务的成功分子。执行器对全部46次非按钮输入机会按每次最多1次路由加6次任务调用极保守估计为322次；这是规划量，不是实际消耗或费用承诺，正式运行仍受单独授权的硬上限约束。

运行前后核对题集、协议、源码、提示配置、判分器、二进制、曲库真值和公开模型策略。中途改变会使该次质量验收无效，不能取其中最好结果。

## 会得到哪些指标

| 指标 | 看什么 | 不代表什么 |
| --- | --- | --- |
| 本轮任务完成率 | 一个完整场景的所有必要目标和最终状态是否成立 | 自动契约通过或模型接口返回成功 |
| 意图与行动契约准确率 | 每条自然语言是否选择了允许的行动，是否遗漏、多派或越权 | 后台路由状态叫completed |
| 关键槽位准确率 | 歌名、歌手、版本、目标曲数、保留数、时长和操作权限等 | 提示词里出现了正确关键词 |
| 安全与恢复 | 是否未经确认写偏好、误播放、用错候选或重发未知请求 | 所有攻击都已覆盖 |
| 延迟与调用量 | 输入到稳定、模型请求耗时、次数、结果和Token | 生产性能、金额预算或账单 |

全部已选题都保留在分母中。失败、未知、前置阻塞、未执行分别列出；未决结论存在时，不给完整质量点估计，只给已确认通过下界和可能上界。自然语言与按钮动作分别统计，新题与回归分别统计。

新题只有16个，一题就影响6.25个百分点。因此成绩只能描述这批自建题，不能称作真实用户总体准确率。

关键字段记录来源：路由结果中的歌名/歌手/版本/操作，与编译后的任务曲数/保留数/目标分钟分别核验。提供micro、macro及逐轮全对率；没有完整标注的额外槽位错误保持未知。版本选择主要核对正确ID和路由参数，本轮没有独立验证所有UI版本标签。

## 哪些能自动判断，哪些需要复核

固定真值能自动核验曲目ID和顺序、明确版本、数量、日期、偏好完整内容及revision、任务终态和实际播放。原判分器的“歌单非空”“搜索HTTP命中”“存在当前任务”和“偏好包含某词”都不足以独立证明业务完成，本轮需要更具体的最终判据。

推荐相关性、解释完整性和必要澄清仍需语义复核。人工结论标注具名人工；开发Agent的判断标注为Agent复核，不能冒充人工评分。机器已经证明的越权、未执行或未知结果不能靠人工表改成通过。

本轮包含引号、条件、取消偏好后的旧确认重放、跨会话候选和原任务控制边界，**不覆盖完整对抗攻击面**。24题没有专门的工具文本注入或真实unknown付费请求夹具，这两类指标保持未评测。工具文本攻击必须证明字段实际到达模型或执行决策边界；设备白名单过滤只能报告过滤事实。旧评测中未触达的注入、没有真正重放的确认、缺失的unknown原请求夹具，不会挪作本轮已覆盖证据。

## 面试怎么解释

我把工程回归和真实模型质量分开。修复后先冻结新题、允许路由、关键字段和最终目标，用真实Qt走正式后台，所有模型角色共用持久请求预算。评分同时看候选、任务终态、偏好版本和播放事实，不看模型自报成功。新题和回归分开，缺证据留在分母；语义判断与确定性契约分层，开发Agent复核不冒充人工结果，固定曲库也不冒充真实听感。

1. 为什么不直接用路由成功率？路由生成成功仍可能选错动作或没有执行，必须继续验最终状态。
2. 为什么保留未知和没跑的题？否则只统计能跑且成功的题会夸大效果，也看不到执行器的覆盖缺口。
3. 为什么不用模型裁判一键评分？权限和状态有确定性证据；推荐语义需要校准后的复核，未经校准的模型裁判会增加另一层误差和调用成本。
4. 为什么16个新题不能叫总体准确率？它是自建非随机小样本，一题影响很大，也没有覆盖真实用户分布。
